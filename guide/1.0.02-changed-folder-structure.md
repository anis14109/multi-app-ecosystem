# Changed Folder Structure

This project uses a custom folder structure to support shared hosting deployment, where the web root must be the project root directory.

## What Changed

- All Laravel root files and folders were moved into the `apps/` directory.
- The `public/` folder contents were copied to the project root.
- `index.php` was modified at the root to bootstrap Laravel from `apps/`.
- `.htaccess` was added to deny direct access to the `apps/` folder.

## Folder Structure


## Root `index.php`

```php
<?php

use Illuminate\Foundation\Application;
use Illuminate\Http\Request;

define('LARAVEL_START', microtime(true));

// Determine if the application is in maintenance mode...
if (file_exists($maintenance = __DIR__.'/apps/storage/framework/maintenance.php')) {
    require $maintenance;
}

// Register the Composer autoloader...
require __DIR__.'/apps/vendor/autoload.php';

// Bootstrap Laravel and handle the request...
/** @var Application $app */
$app = require_once __DIR__.'/apps/bootstrap/app.php';

$app->handleRequest(Request::capture());
```

## Root `.htaccess`

```apache
<IfModule mod_rewrite.c>
    <IfModule mod_negotiation.c>
        Options -MultiViews -Indexes
    </IfModule>

    RewriteEngine On

    # Deny direct access to apps folder
    RewriteCond %{REQUEST_URI} ^/apps/ [NC]
    RewriteRule ^ - [R=403,L]

    # Handle Authorization Header
    RewriteCond %{HTTP:Authorization} .
    RewriteRule .* - [E=HTTP_AUTHORIZATION:%{HTTP:Authorization}]

    # Handle X-XSRF-Token Header
    RewriteCond %{HTTP:x-xsrf-token} .
    RewriteRule .* - [E=HTTP_X_XSRF_TOKEN:%{HTTP:X-XSRF-Token}]

    # Redirect Trailing Slashes If Not A Folder...
    RewriteCond %{REQUEST_FILENAME} !-d
    RewriteCond %{REQUEST_URI} (.+)/$
    RewriteRule ^ %1 [L,R=301]

    # Send Requests To Front Controller...
    RewriteCond %{REQUEST_FILENAME} !-d
    RewriteCond %{REQUEST_FILENAME} !-f
    RewriteRule ^ index.php [L]
</IfModule>
```

## Shared Hosting Notes

- The `apps/` directory is protected from direct web access via `.htaccess`.
- All HTTP requests go through the root `index.php`, which forwards them to Laravel.
- Make sure your hosting provider supports Apache `mod_rewrite`.
