# Installation from GitHub

## Step 1: Clone the Repository

```bash
git clone https://github.com/anis14109/multi-app-ecosystem.git
```

## Step 2: Navigate into the Project Folder

```bash
cd multi-app-ecosystem
```

## Step 3: Install Composer Dependencies

```bash
cd laravel-api
composer install
composer install --optimize-autoloader --no-dev
```

## Step 4: Copy Environment File

```bash
cp .env.example .env
```

## Step 5: Configure Database

Edit `.env` and update the database credentials:

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=laravel-api
DB_USERNAME=root
DB_PASSWORD=
```

## Step 6: Generate Application Key

```bash
php artisan key:generate
```

## Step 7: Run Database Migrations

```bash
php artisan migrate

# if need dummy data
php artisan migrate --seed

# if need fresh database & dummy data
php artisan migrate:fresh --seed

# Run only the specific migration file
php artisan migrate --path=database/migrations/xxxx_xx_xx_xxxxxx_create_users_table.php

# 2. Seed only the specific seeder class
php artisan db:seed --class=ExamTermSeeder --force
```

## Step 8: Start the Development Server

```bash
php artisan serve
```

Or visit locally, Or run server with Local ip

http://192.168.0.151/multi-app-ecosystem/laravel-api/public/

```bash
php artisan serve --host=192.168.0.151 --port=8000
```
