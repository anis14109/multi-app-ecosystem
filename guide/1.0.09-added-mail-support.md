# ADDED MAIL SUPPORT
Added webmail support from webmail smtp server.
---
Add your mail provider credential info-
## `.env`
```
MAIL_MAILER=smtp
MAIL_SCHEME=null
MAIL_ENCRYPTION=ssl
MAIL_HOST=mail.yourdomain.com
MAIL_PORT=465
MAIL_USERNAME=info@yourdomain.com
MAIL_PASSWORD=info@yourpassword
MAIL_FROM_ADDRESS="info@yourdomain.com"
MAIL_FROM_NAME="${APP_NAME}"
MAIL_GLOBAL_BCC=info@yourdomain.com
```

## If you want to send BCC to the main inbox. because send mail don't save in inbox.
BCC in email stands for blind carbon copy, which is a feature that sends a copy of a message to someone while keeping their email address hidden from all other recipients.

# `apps\app\Providers\AppServiceProvider.php`
```
<?php

namespace App\Providers;

use Illuminate\Support\Facades\Route;
use Illuminate\Support\ServiceProvider;
use Livewire\Livewire;
use Illuminate\Support\Facades\Event; // Import the Event facade
use Illuminate\Mail\Events\MessageSending; // Import the MessageSending event

class AppServiceProvider extends ServiceProvider
{
    /**
     * Register any application services.
     */
    public function register(): void
    {
        //
    }

    /**
     * Bootstrap any application services.
     */
    public function boot(): void
    {
        $this->configureLivewireRoutes();
   	
        // Listen to every outgoing email right before it sends
        Event::listen(MessageSending::class, function (MessageSending $event) {

            // Add the BCC address if it exists in your .env file
            $bccAddress = env('MAIL_GLOBAL_BCC');
            if ($bccAddress) {
                $event->message->addBcc($bccAddress);
            }
        });
    }

    /**
     * Override Livewire's default update route to include the subdirectory
     * prefix from APP_URL. Without this, Livewire generates root-relative
     * URLs like "/livewire/update" which break in subdirectory deployments.
     */
    protected function configureLivewireRoutes(): void
    {
        $urlPrefix = rtrim(parse_url(config('app.url'), PHP_URL_PATH) ?? '', '/');

        Livewire::setUpdateRoute(function ($handle) use ($urlPrefix) {
            return Route::post("{$urlPrefix}/livewire/update", $handle)
                ->middleware('web')
                ->name('livewire.update');
        });
    }
}
```
